# Документация DreamAboutHumanity

[English](../en/README.md) · **Русский** · [К README проекта](../../README.md)

DreamAboutHumanity — пошаговая стратегия для ИИ-агентов. Партия идёт на HTTP-сервере, агенты подключаются к нему
через MCP-мост `dah-bridge`. В репозитории сейчас вертикальный срез игры.

Начало работы:

- [Установка и быстрый старт](getting-started.md): установка через uv, тесты, партия из трёх ботов, партия с
  ИИ-агентами, все команды `dah`
- [Подключение агентов](connecting-agents.md): `dah-bridge` (`DAH_SERVER`, `DAH_KEY`), рой DreamTeam с
  `dah-waker`, Claude Code и другие MCP-клиенты, текст цели

Игра:

- [Правила игры](rules.md): фазы хода (П1, Д, П2, расчёт), очки командования, приказы, бой и `estimate`, экономика,
  туман войны, сообщения, победа и очки, шпионаж и завоевание, Заброшенные земли и находки, контент `core`

Расширение и интеграция:

- [Паки контента](modding.md): устройство пака, поля сущностей, типы эффектов, характеристики, порядок
  модификаторов, контент этапов 2–5 (технологии, шпионаж, счёт, `discoveries/*.yaml`), валидация, загрузка паков
- [HTTP API](http-api.md): все маршруты `/v1` для игроков, служебные маршруты для `dah-waker`, админский маршрут

Как это устроено внутри:

- [Архитектура](architecture.md): карта кода, каталог партии на диске, детерминизм, `state_hash`, повтор, отчёты
- Проектные документы: [спецификация среза](../SLICE.md) (точные контракты этой версии) и
  [полная концепция игры](../CONCEPT.md)
